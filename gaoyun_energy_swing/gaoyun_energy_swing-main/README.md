# 基于 FPGA 的旋转倒立摆实时姿态控制系统

> 高云 GW2A-55C + J280 开发平台 · 一级旋转倒立摆（Furuta Pendulum）
> 自动起摆 · 倒立自平衡 · 抗外部推力 · 摆臂定点位置控制 · 正弦轨迹运动

---

## 一、系统简介

本项目在单片 FPGA 内实现一级旋转倒立摆的**全部实时控制逻辑**，主频 50 MHz，控制周期 3 ms（333 Hz）：

| 功能 | 实现方式 |
|---|---|
| **自动起摆** | 能量法：用摆杆能量误差驱动摆臂泵能/抽能，把静止下垂的摆杆抬到垂直位 |
| **倒立自平衡** | 倾角环 PD+I 输出 PWM 占空比与方向，实测可连续稳定 100 秒以上 |
| **抗外部推力** | 上述环路对轻微推力可在数十毫秒内拉回（实测多次推力扰动全部恢复） |
| **摆臂定点位置控制**（拓展1）| 位置环 PD+I + 目标斜坡，**按键设定目标**，平滑移动并保持 |
| **正弦轨迹运动**（拓展2）| 摆臂按 20 秒周期正弦往复，**摆杆全程保持直立**（拓展3）|

摆杆角度用 10 位 ADC 采样（精度 0.088°），摆臂用电机自带增量编码器（1138 counts/圈），**全部控制律在 FPGA 内部以纯硬件逻辑运算，无软核、无 CPU**。

## 四、操作说明（按键）

| 按键 | 功能 | 说明 |
|---|---|---|
| **SW5** | 全局复位 | 复位后状态机回 `IDLE`，摆臂目标档位归 0 |
| **SW1** | 启动 / 停止 自动起摆 | 按一次开始起摆，再按一次停止（停止后电机不输出）|
| **SW2** | 摆臂位置档循环 | `中(0°) → 左(+285 counts≈90°) → 右(−285 counts≈−90°) → 中` |
| **SW3** | 进出正弦轨迹模式 | 进入后摆臂按 20 秒周期往复，再按一次退出 |

### 典型演示流程

```
1. 上电 → 按 SW5 复位
2. 让摆杆自然下垂静止 → 按 SW1 → 约 3~10 秒后摆杆立起并稳定
3. 轻推摆杆 → 系统自行拉回（抗扰演示）
4. 按 SW2 → 摆臂平滑移动到指定档位并保持（拓展1）
5. 按 SW3 → 摆臂开始正弦往复，摆杆保持直立（拓展2、3）
6. 再按 SW1 → 停止
```

## 六、控制算法

### 6.1 起摆（能量法）

```
E      = KIN_GAIN·ω² + (cosφ − 16384)        // 倒立位 E=0，下垂静止 E 最小
dir    = sign(ω · cosφ)                       // 能量注入方向
u_swing = −sign(E − E_REF) · |u| · dir        // 能量不足则泵能，过量则抽能
```

`E_REF = −300`（略低于"刚好到达顶部"的能量），使摆杆在顶部附近速度很小便于捕获。
驱动力幅值按能量偏差成比例，并在 `[u_min_swing, u_max_swing]` 之间限幅。

### 6.2 平衡（倾角环 + 位置环）

```
u_bal = KP_THETA·φ + KD_THETA·ω_slow + KI_THETA·∫φ
      + KP_POS·(θ−θ_ref)/4 + KD_POS·θ̇ + KI_POS·∫(θ−θ_ref)/4
```

- 摆杆角速度来自 **α-β 滤波器**（`phi_pred = φ̂ + ω̂` 后做增益修正），比直接差分噪声更低
- 积分器带**条件抗饱和**（输出饱和时停止积分）
- 两个环的输出经**权重 α 平滑混合**：

```
u = [α·u_bal + (256−α)·u_swing] / 256
α 由 |φ| 和 |ω| 距倒立点的远近共同决定（各 64 LSB 线性过渡区）
```

避免了"起摆↔平衡"硬切换对电机的阶跃冲击。

### 6.3 捕获判据

进入平衡态要求**同时**满足并**连续保持 5 拍（15 ms）**：

```
|φ| < phi_catch(150 LSB = 13.2°)   且   |ω| < omega_catch(10 LSB/3ms ≈ 293°/s)
```

> 连续 5 拍的要求用于**拒绝高速掠过顶部**的假捕获。

### 6.4 拓展1：摆臂定点位置控制

- 参考点 `arm_ref` 在非平衡态持续跟随当前编码器值，进入平衡后**锁存**（中途掉落不会冲掉目标）
- 目标 = `arm_ref + arm_off`，由**斜坡发生器**以 **1 count/3 ms**（≈105 °/s）平滑逼近
- 安全限幅：`|φ| > MOVE_PHI_MAX(170 LSB = 15°)` 时**暂停目标推进**，摆杆回正后继续
  （保证"位置移动过程中摆杆始终保持直立"）

### 6.5 拓展2：正弦轨迹运动

- 目标 = `arm_ref + TRAJ_A·cos(2πt/T)`，`TRAJ_A = 400 counts`，`PH_STEP = 10065` → **周期 20.0 s**
- 相位由计数器累加 + `cos_lut` 查表实现，含**流水寄存器**以满足 50 MHz 时序
- **软启动**：进入轨迹时相位归零 + 幅度在 2.3 秒内 0→满幅，避免目标阶跃把摆杆甩倒
- 周期必须**显著长于位置环带宽**（约 0.15 Hz / 6.7 s）才跟得上；实测 8 s 周期时摆臂只跟到 1/3

## 七、关键参数（`src/param_cfg.v` 默认值）

| 参数 | 值 | 含义 |
|---|---|---|
| `KP_THETA` | 20.0 | 倾角环 P |
| `KD_THETA` | 90.0 | 倾角环 D |
| `KI_THETA` | 8.0 | 倾角环 I（Ti ≈ 2 s）|
| `KP_POS` | 24.0 | 位置环 P |
| `KD_POS` | 65.0 | 位置环 D（捕获后 3 秒内由 0.75×软启动到 1.0×）|
| `KI_POS` | 1.0 | 位置环 I |
| `U_MAX_BAL` | 2000 | 平衡输出限幅（占空比 ≈50%）|
| `U_MIN_SWING` / `U_MAX_SWING` | 700 / 1800 | 起摆输出下限 / 上限 |
| `PHI_CATCH` / `OMEGA_CATCH` | 150 LSB / 10 LSB | 捕获角 / 角速度阈值 |
| `PHI_TOP` | 150 LSB | 顶部穿越判定 |
| `PHI_FALL` | 300 LSB（26.4°）| 失稳判据（超过则回起摆态）|
| `ZERO_RAW`（`top.v`）| **2860** | 摆杆"倒立位"对应的 ADC 原始值（需现场标定）|
| `MOVE_PHI_MAX`（`balance.v`）| 170 LSB（15°）| 位置移动时的摆杆倾角上限 |
| `TRAJ_A` / `PH_STEP`（`top.v`）| 400 counts / 10065 | 轨迹幅值 / 周期 20 s |

### ⚠️ 零点 `ZERO_RAW` 必须现场标定

ADC 零点会随温度、重新安装而漂移。**标定方法：**

```
1. 让摆杆自然下垂静止，读串口上报的 phi
   正常应为 ±2048 LSB（±180°）
2. 若读数为 X（偏离 2048 差值 D = 2048 − |X|），则
   ZERO_RAW 新值 = 旧值 − D
3. 改 top.v 里 angle_proc 的 .ZERO_RAW(12'dxxxx) 后重新编译
```

零点偏差 6° 就会导致"摆臂持续单向旋转"——因为恒定倾角产生恒定力矩，而恒定力矩等于恒定角加速度。

## 八、串口通信协议（115200 8N1）

### 8.1 遥测上报（FPGA → PC，每 3 ms 一帧，**10 字节**）

```
[0]AA [1]55 | [2..3] phi | [4..5] enc_pos1 | [6..7] 状态字 | [8]0D [9]0A
```

| 字节 | 字段 | 含义 |
|---|---|---|
| 2~3 | `phi[15:0]` | 有符号 16 位，摆杆倾角（ADC LSB，0 = 倒立，1 LSB = 0.0879°）|
| 4~5 | `enc_pos1[15:0]` | 摆臂编码器计数（无符号 16 位，会卷绕；1138 counts/圈）|
| 6~7 | 状态字 | `{state[1:0], p_wr_tog, motor_cmd[12:0]}`<br>`state`：0=IDLE 1=SWING 2=BALANCE<br>`p_wr_tog`：每收到一帧合法参数帧翻转一次（用于确认参数已写入）<br>`motor_cmd[12:0]`：有符号 13 位电机指令（−3000~+3000）|

> 说明：`motor_cmd` 在包内是 13 位补码，解析时若 ≥ 0x1000 需减 0x2000 才是真实有符号值。
> 该"调试打包格式"便于观测状态与指令；若需原始格式，可改回 `{enc_pos1, enc_pos2}` 两个 16 位字段。

### 8.2 参数配置（PC → FPGA，6 字节）

```
AA 55 | idx | val_H | val_L | chk        (chk = idx + val_H + val_L 的低 8 位)
```

| idx | 参数 | idx | 参数 |
|---|---|---|---|
| `0x00` | 起停（等价按 SW1）| `0x09` | `omega_catch` |
| `0x01` | `kp_theta` | `0x0A` | `phi_top` |
| `0x02` | `kd_theta` | `0x0B` | `phi_fall` |
| `0x03` | `kp_pos` | `0x0C` | `ki_theta` |
| `0x04` | `kd_pos` | `0x0D` | `ki_pos` |
| `0x05` | `u_max_bal` | `0x0E` | `arm_off`（臂目标偏移，counts）|
| `0x06` | `u_min_swing` | `0x0F` | `traj_sw`（轨迹远程开关，非 0 启用）|
| `0x07` | `u_max_swing` | | |
| `0x08` | `phi_catch` | | |

> **增益类参数（0x01~0x04、0x0C、0x0D）以 0.1 为单位下发**：
> 例如要设 `kd_theta = 90.0`，下发 **900**；固件内部换算为 Q4 存储。
> 其余为整数原值。参数**掉电丢失**，按 SW5 复位会恢复默认值。

## 十一、已知限制与使用注意

| 限制 | 说明 |
|---|---|
| **摆臂存在固有往复摆动** | 一级旋转倒立摆是**欠驱动系统**（1 个电机控制 2 个自由度），扶住摆杆必然需要摆臂运动，无法同时把摆臂完全锁死。赛题基础要求的三条指标均针对**摆杆**，本工程摆杆精度 `\|φ\|` 平均 < 2.5° |
| **零点需定期标定** | 见第 7 节。上电后若发现摆臂持续单向旋转，先查 `ZERO_RAW` |
| **`kd_theta` 不能随意下调** | 实测降至 60/75 时起摆**无法捕获**（会在顶部掠过而抓不住），故保持 90 |
| **轨迹周期不可过短** | 位置环带宽约 0.15 Hz，周期 < 10 s 时摆臂跟不动、波形严重畸变 |
| **长时间运行需注意线缆** | 摆臂累计转动圈数过多会绕线，建议单次演示 ≤ 2 分钟，或中途手动归中 |
| **摆杆存在约 5.5 Hz 微颤** | 由速度估计延迟引起的环路极限环（RMS ≈ 1.2°），是当前精度主要限制，可通过改进观测器进一步抑制 |
